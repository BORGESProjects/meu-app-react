# Catálogo de provas públicas

Atualizado em 2026-10-22; período consultado: 1996–2026.

O catálogo do site indexa 27,017 PDFs de 8 bancas/instituições. Ele contém metadados e links para as fontes de origem, não cópias dos documentos. O pacote integral local é muito grande para ser enviado como parte do site.

Os PDFs e textos extraídos ainda não são questões estruturadas; para entrar no banco corrigível, cada questão precisa ser revisada e ter alternativas e gabarito confirmados. A disponibilidade pública de um arquivo não equivale a uma licença geral de republicação.
